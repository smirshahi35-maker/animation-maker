# استوری نرخ ارز

استوری اینستاگرام (1080×1920) برای نرخ دلار، درام و یورو به تومان، با همان سبک آگهی هاستل: پس‌زمینهٔ سبز تیره، تیتر و قاب‌های طلایی، کارت‌های کرم.

نرخ‌ها، درصد تغییر و شکل نمودارها در آرایهٔ `RATES` داخل `story.html` هستند. برای نرخ‌های تازه همان‌جا را عوض کنید و دوباره رندر بگیرید:

```bash
NODE_PATH=$(npm root -g) node render.js   # → ../deliverables/currency-story.png
```
