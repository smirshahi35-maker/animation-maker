# ادیت سینمایی کلیپ رانندگی شبانه

خروجی: `deliverables/night-drive-cinematic.mp4` (۱۹۲۰×۱۰۸۰، کادر ‎2.39:1 با نوار سیاه، ۲۴ فریم، ‎16.5 ثانیه، بدون هیچ نوشته‌ای)

## صدا

فقط آهنگ خود کلیپ (ضبط ماشین)، بدون هیچ صدای اضافه. آهنگ از فریم اول همراه تصویر شروع می‌شود و تا روشن شدن چراغ‌ها کاملاً هم‌زمان است. وقتی چراغ‌ها خاموش می‌شوند، با کمی ریورب خودش آرام محو می‌شود. بلندی صدا در خروجی روی حدود ‎-14 LUFS است.

## ساختار ادیت

| زمان خروجی | منبع | اتفاق |
| --- | --- | --- |
| ‎0–4.87 | ‎0–4.87 | فید از سیاهی، کابین تاریک، زوم آهسته |
| ‎4.87 | ‎4.87 | روشن شدن چراغ‌ها: فلش نور و پانچ زوم |
| ‎4.87–6.5 | ‎4.87–5.6 | اسلوموشن ‎0.32x (با درون‌یابی حرکت) و برگشت نرم به سرعت عادی |
| ‎12.74 | ‎11.90 | خاموش شدن چراغ‌ها، دیده شدن شهر، آهنگ محو می‌شود |
| ‎12.74–16.1 | ‎11.9–13.93 | سرعت ‎0.6x، زوم آرام به سمت نور شهر، فید به سیاهی |

## کیفیت تصویر

1. **حذف نویز زمانی با جبران حرکت:** هر فریم با دو فریم قبل و بعدش، که با optical flow (DIS) روی هم منطبق شده‌اند، میانگین گرفته می‌شود. جاهایی که حرکت درست منطبق نشود (مثل دست راننده) کنار گذاشته می‌شوند تا شبح نیفتد.
2. **لرزش‌گیر:** مسیر دوربین روی کابین ماشین (داشبورد، صندلی‌ها، ستون‌ها) ردیابی و نرم می‌شود. جاده بیرون در این ردیابی حساب نمی‌شود.
3. **ساخت فریم میانی با optical flow:** برای تبدیل ۳۰ به ۲۴ فریم و برای اسلوموشن. جایی که دو جهت flow با هم نخوانند، فریم نزدیک‌تر استفاده می‌شود.
4. **یک بار نمونه‌برداری (Lanczos)** به کادر ‎2.39:1، کمی شارپ، و پردازش ۱۶ بیتی تا انکود نهایی.

## نور و رنگ

سایه‌های فیروزه‌ای، قرمزهای زنده (خوشبوکننده و برچسب)، مشکی عمیق، هاله و بلوم روی نورها، رگهٔ افقی آنامورفیک روی نورهای تند (چراغ، نمایشگر ضبط، شهر)، گرین ریز فیلم، ویگنت و کمی اعوجاج رنگی لبه‌ها.

## ساخت دوباره

```bash
pip install opencv-python-headless scipy numpy
export NIGHT_DRIVE_SRC=/path/to/20261123_022028.mp4
cd night-drive/tools
python3 render_audio.py mix.wav
python3 render_video.py video.mp4      # H.264 بدون صدا (حدود ۱۰ دقیقه روی ۴ هسته)
ffmpeg -i video.mp4 -i mix.wav -map 0:v -map 1:a -c:v copy \
  -af volume=-3.5dB -c:a aac -b:a 256k -ar 48000 \
  -movflags +faststart ../../deliverables/night-drive-cinematic.mp4
```
