# Fonts

Put `AbarHigh-Regular.otf` in this folder before rendering.

The font is licensed from fontiran.com and this repository is public, so the file is
git-ignored and is never committed.

`Oswald-Variable.ttf` (Latin name lockup, «Steve Jobs» / «NeXT») is SIL Open Font License 1.1
(`OFL-Oswald.txt`) and is committed.
