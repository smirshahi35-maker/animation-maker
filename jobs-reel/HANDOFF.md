## Changing a scene

All scenes are generated by `python3 tools/build_scenes.py`; never hand-edit `compositions/sNN.html`.
Snapshot the scene (`npx hyperframes snapshot --at <t> --no-end`), then adjust its function.

- Moving a drawing: per-scene CSS `#sNN-cam img { top: …px; }` (default −64).
- Keep text inside x 96–984, y 190–1500 (Reels UI covers the bottom).
- Text blocks (`.txt`) are flex columns so the layout audit does not read AbarHigh's tall glyph boxes
  as line collisions; decorative glyphs behind other text (`#s03-year`, `#s01-q`) carry
  `data-layout-allow-overlap`.
- `inout()` fades each scene's `.txt` and `.handoff` elements just before the next scene's first
  word (the build runs twice to learn those times). Give any other large text that sits where the
  next scene's text lands the `handoff` class.

Replacing a drawing: put the new PNG at the `file` path in `tools/image_prompts.json`, then
`python3 tools/prep_images.py` (writes `sNN.webp`, `sNN-lines.webp`, and the s03/s07 cutouts).

## Assemble, check, render, master

```bash
python3 tools/build_scenes.py && python3 tools/build_root.py   # build_root keeps the carve/fade attributes
npx hyperframes check                                          # must be 0 errors
npx hyperframes render -q high -f 30 -o renders/jobs-reel.mp4
# two-pass loudnorm to -14 LUFS / -1.5 dBTP, video copied
ffmpeg -i renders/jobs-reel.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -   # read measured_*
ffmpeg -i renders/jobs-reel.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11:measured_I=…:measured_TP=…:measured_LRA=…:measured_thresh=…:offset=…:linear=true -c:a aac -b:a 192k -movflags +faststart ../deliverables/jobs-reel.mp4
```

If the narration ever changes, re-run the carve for `music-story`, `music-pitch`, `music-pitch-end`
(`node ~/.claude/skills/hyperframes-audio/scripts/carve.mjs --comp index.html --bed <id> --voice narration --strength 0.6`)
and then `python3 tools/add_fades.py` (carve rewrites `data-automation`).
